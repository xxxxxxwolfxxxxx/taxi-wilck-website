# Taxi Wilck Website

Statische Website für den Taxi- und Fuhrbetrieb Wilfried Wilck, Hagenow. Netlify-Vorschau: https://taxi-wilck-hagenow.netlify.app

**Für das Code-Review zuerst lesen: [docs/UEBERGABE.md](docs/UEBERGABE.md)** (Aufbau, Schwächen, Fragenkatalog für den Kunden, Checkliste vor dem Livegang).

```bash
npm run serve   # http://localhost:8099
npm test        # 27 Tests (Node >= 20, keine Abhängigkeiten)
npm run audit   # Links/Meta/JSON-LD aller Seiten
npm run build   # Ortsseiten und gemeinsame Seitenteile neu erzeugen
```
